# 妙记课程剪辑流程技能包

本包覆盖“课程大纲 → 飞书资料/录播检索 → 选材与时间戳 → 语义精剪 → 成片验收 → 云盘上传 → 妙记生成 → 单节课文档与链接回传”。

## 包内技能

- `skills/妙计.skill/`：端到端流程编排与生产清单。
- `skills/口播剪辑.skill/`：课程口播语义剪辑、口癖盘点、字幕/章节条、实现脚本与音视频验收。
- `skills/剪辑.skill/`：可选叙事转场和多镜头衔接；常规屏幕录课不需要调用。
- `dependencies/lark-cli-skill-snapshots/`：本包制作时从本机 lark-cli 导出的 lark-shared、lark-doc、lark-drive、lark-minutes、lark-vc、lark-base 技能与参考文件快照。

## 安装和使用

将 `skills/` 下的技能目录复制到本机 Codex skills 目录（Windows 默认 `%USERPROFILE%\.codex\skills`）。包内 lark CLI 快照用于离线查阅，不是 CLI 的安装包，也不会携带登录凭证。

运行流程前需另外安装/登录 `lark-cli`、配置飞书授权，并安装 FFmpeg。涉及飞书搜索、下载或上传时，以本机当前 `lark-cli skills read <skill>` 返回的规则为准；包内快照可能随 CLI 更新而过期。认证信息、用户私有录播和飞书文档内容均未打包。

## 发布质量门槛

每个剪点需对照逐字稿与原音记录删减依据；“是吧”等高频口癖逐次判断并留存保留/删除清单。导出后正常速度完整听审全片，发现非功能性口癖、气口突兀、断句或拼接不连贯就返修重导、复听通过后再上传。编码检查和抽样看片不代替完整听审。

单节课文档模板链接由主 skill 指向用户指定的飞书模板。使用者需对该文档具有访问权限。
